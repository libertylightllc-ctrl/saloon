# Roadmap — features salons ask about that Saloqo does not have yet

Checked in the code on 25 Oct 2026 (full update brief, Phase 6 j). None of these is mentioned on the website.

| Feature | Today |
|---|---|
| Client appointment reminders (WhatsApp / SMS) | Not built. Reminders today are for the salon itself: licences and documents before they expire, and patch tests before colour services. Receipts can be sent on WhatsApp by the cashier (a link that opens WhatsApp), but nothing is sent to clients automatically. |
| Memberships (monthly plans for clients) | Not built. |
| Packages (e.g. 5 haircuts paid in advance) | Not built. |
| Gift cards and vouchers | Not built. |
| Coupons / promo codes | Not built. A manual discount can be given at checkout. |
| Loyalty points | Not built. |
| Card terminal or payment gateway for the salon's own sales | Not built. Card and wallet sales are recorded by the cashier (the money is taken on the salon's own terminal). Saloqo's own plan payments use Creem; that is for Saloqo's subscription, not for salons' clients. |
