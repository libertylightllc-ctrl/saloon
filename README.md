# Salon Control MVP

Clickable prototype for a barber shop daily-control system.

## Features

- Front page and role-based login
- Owner dashboard
- Quick sale flow
- Editable services with English, Arabic, Hindi and Urdu names
- Purchases with qty, unit, unit cost, discount and total calculation
- Expenses with saved records
- Inventory and reusable tools overview
- Cash closing
- VAT optional settings
- Daily closing report

## Run Locally

```bash
python3 -m http.server 5182 --bind 127.0.0.1
```

Then open `http://127.0.0.1:5182/`.
